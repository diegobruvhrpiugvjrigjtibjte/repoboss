How a challenge is born and judged

Every number RepoBoss reports comes from running your real test suite. Nothing is estimated.

1

Snapshot

Read-only, content-addressed copy of your repo. Secrets, symlinks and caches are left out.

›
2

Inject a bug

Located on the syntax tree (tree-sitter / ast): a constant, a file reference or a boundary condition.

›
3

Prove it

original ✓ passes
with bug ✗ tests fail
restored ✓ passes

Compile errors don't count.

›
4

Agent attempts

Tests hidden, configs read-only, isolated runner with no network. Any agent: Ollama, OpenAI-compatible, your own tool.

›
5

Judge

Only allowed changes go into a clean tree with the protected tests. Patch, tokens, time and outcome are recorded.
